## Installation

Pull the image from GitHub Container Registry:

`docker pull ghcr.io/kimusan/tachyon:latest`

Image packages page: https://github.com/kimusan/Tachyon/pkgs/container/tachyon

Docker Compose examples are here:
https://github.com/kimusan/Tachyon/tree/master/examples/docker

## Persistent data
The volume is located at `/var/lib/tachyon`.
Read more info at https://docs.docker.com/get-started/05_persisting_data/

## readonly configuration mount
Currently not possible.
